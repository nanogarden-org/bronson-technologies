# Portfolio

## Current status

This directory is a structured portfolio scaffold with capability-area candidates. Some entries are documentation-only or still awaiting public demonstration runs.

Each project directory should contain a README covering:

- the problem and constraints;
- the author's role;
- system design and artifacts;
- evidence and verification;
- outcome and limitations;
- privacy and rights boundary; and
- the next test or release gate.

Use synthetic or redacted demonstrations when the original source material is protected. Do not promote a claim's maturity beyond the evidence recorded in `../evidence-index.md`.
