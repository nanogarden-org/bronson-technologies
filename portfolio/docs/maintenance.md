# Maintenance

1. Update `proof-map.yaml` first.
2. Mirror the change to `proof-map.json` and `data/search-index.json`.
3. Update the relevant human-facing HTML page.
4. Prefer links to public implementation evidence over duplicated claims.
5. Preserve historical evidence wording and interpretation boundaries.
6. Verify external validators and public links.
7. Commit with an evidence-specific message rather than a generic portfolio update.
