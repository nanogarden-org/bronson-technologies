## Current portfolio candidate

### Phonic Drive Analyzer

A batch-capable acoustic analysis and state-space measurement engine under active refinement as a public portfolio release candidate.

**Demonstrates:**

- analytical system decomposition;
- batch processing and machine-readable outputs;
- measured-versus-interpretive layer separation;
- state-space and transition analysis; and
- reproducible technical workflow design.

**Repository:** `nanogarden-org/phonic-drive-analyzer`

**Current maturity:** private prototype / release candidate.

**Public-release gate:** complete hardening, documentation, example outputs, provenance metadata, and final claims review before changing the separate repository's visibility. This repository does not claim that the analyzer is public or production-ready.
