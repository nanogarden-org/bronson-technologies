# Demos

## Current status

No portfolio demonstration has been published in this directory yet. The currently runnable public-safe demonstration is the simulated ABCI emitter under [`platforms/abci/examples/python/`](../platforms/abci/examples/python/).

A demo added here should be runnable or inspectable by an outside reviewer and should include:

- prerequisites and setup;
- sample input;
- expected output;
- limitations and failure behavior; and
- a privacy-safe synthetic, public-domain, licensed, or user-owned dataset where needed.

Do not publish private source material or imply production, clinical, or security validation from a demonstration alone.
