Weekly update guide

When a new credential is approved for publication:

  1. Copy one <article class="credential-card"> block from the current credentials section.
  2. Replace the issuer, title, issue date, ID, description, and official source link.
  3. Update the visible Last reviewed date and its matching datetime value.
  4. Add the related project or tool only when there is inspectable evidence, and keep planned work in the roadmap.
  5. Do not upload certificate originals, private IDs, QR codes, passwords, or client data.

For a source change or correction, update the card and the repository's evidence index together so the public page remains traceable.
